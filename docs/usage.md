# 使用指南

MaaPJSK 用于日服 Project SEKAI，通过 MFAAvalonia 已连接的 MaaFramework 控制器操作游戏。基准环境为 MuMu、横屏 1280×720、240 DPI；其他设备、区服或分辨率需要另行适配。

## 安装与连接

1. 从 [Releases](https://github.com/coatcn1/MaaPJSK/releases) 下载完整 Windows x64 ZIP，完整解压后双击 `MaaPJSK.cmd`。
2. 首次启动会准备随包 Python，无需另装开发环境；在 MFA 中选择自己的 MuMu 连接。
3. 在「谱面管理」同步本地曲库，并在「演奏设置」确认引擎、偏移和体力设置。
4. 添加所需任务，选择曲目方式、难度与次数，再手动开始。

安装、更新和本机数据保留见 [Windows 运行包](release-package.md)。源码运行环境及固定 PowerShell 启动入口见 [开发指南](../CONTRIBUTING.md)。

## 选择任务

| 任务 | 使用方式 |
| --- | --- |
| 🎶 自动演出 | 使用游戏内 AUTO LIVE，从主页进入当前歌曲或随机歌曲并循环结算。 |
| 🎼 单人谱面演出 | 按本地 SUS 派发触控，支持当前歌曲、随机选取或本地完整曲名搜索，详见[单人说明](solo-chart-live.md)。 |
| 🤝 协力谱面演出 | 支持自由／资深公房、当前提名或随机，按实际抽选歌曲确认本地谱面，详见[协力说明](cooperative-chart-live.md)。 |
| ▶️ 一键演出 | 用户手动选歌和准备，任务等待最终开场后演奏一曲，保留结束页面，详见[一键说明](one-shot-chart-live.md)。 |
| 🎯 Native 谱面校准 | 同曲一次排练、一次正式验证，成功后保存匹配环境与难度的校准配置，详见[Native 与校准](native-calibration.md)。 |
| 📺 广告奖励 | 独立的有限广告请求与返回流程，需用户主动选择，详见[广告奖励](ad-rewards.md)。 |

游戏内 AUTO LIVE 与本地谱面演奏是不同任务。谱面任务按本地 SUS 时序触控，屏幕识别负责导航、身份确认、首音同步和生命保护，当前不提供实时音符识别演奏。

一键演出最长等待五分钟最终封面，难度来自任务设置，须与游戏中手动选择一致；任务不改体力、不加载单人校准、不推进结算。首次进程曲库维护结束后，再手动进入开场。

## 演奏设置

在 **MFA 设置 → 演奏设置** 中选择引擎、触控偏移、校准配置和每局体力消耗。修改停止片刻后自动保存；输入不完整、维护占用或保存失败时会提示未保存，处理后再启动任务。

正偏移延后触控，负偏移提前。正常单人任务可使用已验证校准偏移加手动偏移；协力和一键的校准使用边界见各任务说明。更换引擎、设备、游戏版本、控制器链路或流速后，重新核对并校准环境。

## 体力与失败重试

每局体力由用户决定，可沿用游戏设置或指定 0–10；不会因不足自行降低消耗。任务选项中的自动用药默认关闭，开启后只使用指定的小／大饮料补足下一局缺口，不使用水晶或广告补体力。消耗确认与批量到账的详细行为见[单人说明](solo-chart-live.md)和[协力说明](cooperative-chart-live.md)。

**中途失败重试次数** 默认 0 关闭，允许 0–99，预算属于整次普通单人或协力任务。真实死亡的失败局不计入目标，安全释放和退出完成后才重试；身份、首音、连接或普通输入异常不使用该预算，校准、一键和 AUTO 不接入。发生失败的重试任务在清理后显示累计失败次数。

协力确认真实生命归零后先释放触点，再切回模拟器主页；是否重新登录继续由重试设置及安全门槛决定。普通结算返回游戏主页，未知或演奏中页面不会盲目退出。

## 曲库维护

每次打开 MFA 后，首次启动 AUTO、单人、协力、一键或校准任务前，自动执行一次完整默认增量维护；同一进程后续任务不重复。失败或取消不会开始演出，部分资源失败会提示警告，可用曲目仍须通过身份与 SHA256 校验。

手动入口为 **MFA 设置 → 谱面管理 → 增量更新谱面**，只处理新增、变化、缺失或损坏资源。联网复查近三个月资源使用「检查近期资源」。同步、演出和更新不能同时进行；详细来源、维护选项和本地数据布局见[日服谱面库](sekai-chart-repository.md)。公开仓库不分发游戏谱面。

## 日志、缓存与通知

**MaaFramework 日志与调试图** 默认关闭底层框架流水，演出报告、成绩、项目截图与 Native 执行回执继续保存。排查框架问题时开启，自动保存后重启 MFA 生效；历史文件不会自动删除。

**不写入任何日志** 关闭演出报告、成绩 CSV、截图、trace、Native 回执文件及 MFA／MaaFramework 文件日志。进度和错误仍显示在界面，生命保护、触点释放、演奏设置、校准配置和用药消费状态照常工作。框架日志部分需重启，其余诊断按下次任务快照生效；关闭写盘后无法回放该次演出的历史证据。

**关于我们 → 清理缓存** 清除当前运行目录的诊断缓存，保留已保存成绩 CSV、演奏设置、校准配置和下载曲库；任务、同步或更新期间拒绝清理。开发目录中的旧验收与构建文件不属于此按钮的范围。

任务界面显示已完成次数和错误；失败或中途停止不增加完成数，完整成绩与完成次数分别统计。诊断范围和回放方法见[演奏诊断](performance-trace.md)。

**性能设置 → 任务运行中阻止息屏** 只在任务实际运行期间防止 Windows 自动息屏与休眠，结束、失败或停止后释放，空闲窗口不阻止息屏。

## 使用范围与故障处理

不要让多个 MFA、独立 CLI 或其他自动化工具同时控制同一模拟器。游戏 UI、分辨率或设备改变后，应重新确认连接与模板。

本项目是非官方工具。各模式的异常恢复、其他房型／难度以及候选解析功能的验收范围见对应专题和[版本发行说明](release-notes-v0.9.0.md)；既有测试与某首歌曲成绩不代表全曲库准确率。遇到问题时保留对应演出报告，结合实际运行目录、曲名和难度排查。
