# 广告奖励与共用登录

MFA 的 **📺 广告奖励** 默认不勾选，不读取演奏设置或派发谱面触控。任务从主页左上地图进入现实世界的「スクランブル交差点」，最多向左滑三次寻找手机 CM。地图标签和手机图标在当前视口中唯一定位，点击前重新取帧；重启后的世界地图先明确确认「現実世界へ」、无演奏 HUD 并短暂稳定后再切换。该入口最多三次请求、间隔至少一秒，转场和未知页只等待，只有实际城市地图才证明切换成功，不沿用旧坐标或把回执当页面进展。

手机 CM 仅使用已确认的原尺寸及 0.9 倍两个固定尺寸，门槛仍为 0.9；同一对象的近邻尺度命中可合并，两个不同明确手机候选仍拒绝，实际 CM 文字也须确认。CM 点击成功后只作短转场和加载转圈检查，然后直接点击固定左上位置；已在明确奖励页时也直接点击，不读取次数、不等待两帧额度。

每次固定点击 `(249, 328)`，卡片变为四张、三张或一张也不换位置。奖励页只用现有模板、亮度及加载转圈快速判断；观看确认只核对现有问题和按钮模板，不追加文字 OCR。每次最多等约两秒确认弹窗，确认后点击固定 `(760, 542)`；最多三次固定点击未弹出确认就记录「固定位置未弹出观看确认，结束本次点击循环」。首点后页面未知时结束，不追加未知页点击。

请求观看成功后可取消等待 10 秒，然后每秒发送一次 Android 返回键 `KEYCODE_BACK 4`（本文 ESC／BACK）。一帧明确返回奖励页即停止 BACK 并继续固定点击。20 秒无效时只关闭日服包 `com.sega.pjsekai`，使用原共用登录和导航恢复到 CM 入口；正常返回会清空连续重启计数，连续三次 BACK 无效仍恢复游戏后停止追加，不开始第四次。120 秒保留为 BACK 硬上界。用户停止优先，不触碰下载、安装、购买或外部链接按钮。

本次最多请求开始七次。报告只区分开始请求、正常返回和重启，领取数量与当日耗尽状态保持未知；固定位置无确认、达到七次上限或连续三次重启都只表示本次循环结束。加载转圈仍阻止输入，未由本任务请求开始的手动广告不接管。

## 本机模板与报告

图片和生成配置保持 Git 忽略。按 [模板清单](../examples/ad-rewards-template-manifest.json) 保存基准截图后，在项目根目录执行：

```powershell
$pjskPython = Join-Path (Split-Path -Parent (Get-Location).Path) '.tools/Miniconda3/envs/maabangdream/python.exe'
& $pjskPython -X utf8 scripts/build-ad-rewards-templates.py --captures '.local/ad-rewards-captures'
```

输出位于 `.local/ad-rewards-templates/`，配置保存模板及原来源图的 SHA256。正常部署脚本会复制可选广告配置和模板；缺失或哈希不符时仅广告入口拒绝运行，不影响其他任务。主页另复用标准导航模板并核对不透明地图图标，不将透明底栏背景变化作为宽松匹配依据。

部署目录 `debug/ad-rewards-runs/` 中保存原子 `report.json`、返回页及失败截图，记录 `started_ads`、`normal_returns`、`restart_requests` 及结束原因；`completed_ads`、`rewards_claimed`、`daily_exhausted` 均为空，不把返页或重启当领取。共用登录报告位于 `debug/game-login-runs/`。公开仓库不包含截图、UserID、控制器端点或运行配置。

## 共用登录范围

AUTO、单人、校准及协力在任务配置校验后的启动阶段复用 `project_sekai/game_login.py`；广告重启也调用同一服务。外部应用在前台时只启动日服包，不关闭其他应用。日服已经在前台且不是明确标题时不添加登录输入，交回任务原有导航、等待或演奏保护策略。

服务自行启动游戏或识别明确标题后，在统一 60 秒期限内等待实际主页。标题模板与右上三条菜单横线都就绪、且点击前新帧及前台包名再次确认时，最多三次点击 TAP TO START；三横菜单本身不会被点击，也不能单独证明标题。未知、黑白与欢迎加载帧只等待。本次登录后只有固定「お知らせ」标题、三个标签及无演奏 HUD 的新帧同时成立，才最多三次 BACK 关闭公告。

协力登录普通故障在本次 `run` 内交给既有恢复或可取消等待，同一服务保留原登录期限及请求预算。期限耗尽后只允许只读确认用户已经到达的实际主页，不重新登录或重置预算。一键演出仍不导航；演奏中、结算日更突然回标题以及协力真实死亡 HOME 的原有策略保持。

## 本机验收范围

2026-10-07 的最新部署版只导航验收正常结束：实际识别并打开坐标约 415、204 的较小手机 CM，确认五张奖励卡额度为 `[1, 2, 1, 2, 1]`。`navigation_completed=true`、开始广告和领取奖励均为零，保存设置保持不变；原尺寸／0.9 倍的手机定位分支已取得实际导航证据。

此前正式完整任务仍保留原失败：两次请求观看，各自等待 10 秒后发送 18 次 Android BACK，再分别关闭并重启日服游戏，完成标题登录和公告关闭。第一次重启后实际回到 CM 页并重新选择，第二次恢复在世界地图切换时失败。两次都未确认领取，完成奖励数为零、七次额度仍保留；返回奖励页或重启成功不记为领取。

23:37 的原失败帧已显示四张卡，固定左上按钮仍在原位置；旧版强制五个次数框及两帧额度一致，导致奖励页等待二十秒失败且没有开始广告。本轮删除该门槛、按用户原要求固定点击，并通过五卡／四卡真实保存帧无 OCR 回放及四／三／一卡重排回归。新固定点击循环和最终第三次恢复尚未实机验收；历史原始失败与请求统计保留，领取和当天耗尽仍不推算。
