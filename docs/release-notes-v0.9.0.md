# MaaPJSK v0.9.0

本版面向日服 MuMu、Windows x64、横屏 1280×720／240 DPI。MFA v2.12.0、MaaFramework 5.10.2、Native 1.2.0 保持；开场同步为 28，默认触控计划为 4。完整包和更新包均附 SHA256，安装及更新方法见 [发行与更新说明](release-package.md)。

## 变化

- 混合金 TAP 开场保护默认开启：仅处理首颗普通金 TAP 与同轨及异轨后继交叠的窄族，首次仍须原单头证明；丢失不由后继重新播种。开场证据重复保存保留原采样索引与时间。
- AUTO、单人与协力自动用药改为按下一局实际消耗与当前体力的缺口计算瓶数；移除瓶数输入，旧参数仅兼容且不影响自动量。小药按缺口、大药向上取整，不补满十点、不重复未确认批次。
- 单人等待 Live 菜单稳定后进入选曲；指定 APPEND 先搜索目标，再切换该歌曲的难度组。
- 协力完整输入、释放、双帧结算与恢复安全主页证明齐全后补确认已演出，分别显示演出次数与完整成绩数，同 run 成绩索引原子更新。
- 协力入口公告及搜索浮层采用有界恢复。搜索取消需精确 OCR、真实按钮和无 HUD／房内冲突，按新帧与前台复核后有限 BACK；最多三次／20 秒，双帧房间选择及 preflight 才确认返回。普通恢复跨报告保留 120 秒无进展预算，原房内 180 秒和结算登录 60 秒保持。
- 擦除装饰短链解析候选仍默认关闭，仅显式 `MAAPJSK_ERASED_SLIDE_GUARD=1` 启用；启用后使用独立触控版本 6／7，不能复用默认计划的校准。

## 验证范围与已知限制

混合金 TAP 在本机「Life Will Change」EXPERT26 候选及默认入口共两局单人 LIVE CLEAR、完整输入释放和回主页通过；TRACE 首头的历史四局验收限「at」MASTER33 的单人与单人场景一键。入口公告仅有一次关闭、双帧主页和 preflight 的真实导航证据，未入房、未开演。上述证据均不能扩大为全曲库、其他设备或协力异常恢复验收。

**协力搜索超时取消、自动重匹配与共同 120 秒其他异常恢复尚未实机验收。** 保存失败帧的 OCR／模板回放、模拟 BACK、合成安全房间选择及四次入房预算耗尽回归均属离线证据。默认开启的本版在用户知悉这些缺口并明确要求后公开发布，不据此宣称异常恢复已稳定。

按缺口自动用药的完整 AUTO／协力触发、大药多瓶、单人菜单及 APPEND 改动、死亡重试等新增路径仍须各自真实环境验收。历史 v0.8.0 首启、改名及合成更新保留测试不等于本版已完成同项包验收；本版构建与回归结果以本次发布记录为准。

## 回退

停止任务并正常关闭 MFA 后，在新 PowerShell 窗口设置所需环境变量，再从该窗口启动 `MaaPJSK.cmd`，设置只影响该进程及子进程，保护在初始化时冻结：

```powershell
$env:MAAPJSK_COOPERATIVE_ROOM_SEARCH_GUARD = '0'
.\MaaPJSK.cmd
```

该设置关闭搜索取消和共同恢复终态候选，恢复原有等待策略；可能重新出现持续等待，需用户手动停止并处理页面。入口公告可独立用 `MAAPJSK_COOPERATIVE_ENTRY_NOTICE_GUARD=0` 回退，混合金 TAP 可用 `MAAPJSK_GOLD_TAP_MIXED_CONTEXT_GUARD=0` 回退；不保证旧开场路径能处理本版新增覆盖的曲目。擦除候选保持未设置或 `0` 即关闭。恢复默认时关闭 MFA、移除对应环境变量后重新启动。

自动用药与选曲变更没有独立回退开关；遇到问题先关闭自动用药或任务，保留原始错误。需要回到旧整版时，在独立目录解压历史完整包并保留当前配置、曲库与 Profile 备份，不用旧 ZIP 覆盖当前安装或绕过更新器版本检查。
